# 手机上怎么用

打开 Pairfob 后先看到电脑上的会话列表。点一张卡片，打开的就是电脑上那个会话，不是副本，也不是截图。

宽屏（大约平板横屏或桌面浏览器）会走双栏：左边列表，右边会话。手机是一屏一张。从会话左缘右滑可以回到列表。

## 列表

默认 **按工作区** 分组，也就是按项目目录。列表右上角的 **工作区** 按钮打开 **分组方式**：

- **工作区** — 按 Herdr 工作区分组（默认）
- **Agent** — 按 Agent 种类分组
- **全部** — 不分组，一条列表

同一个面板里还有 **全部展开** / **全部折叠**。卡片和分组按你最近点开的顺序排，状态变化不会挪动位置。

分组后点标题可以展开或折叠。默认只展开第一组，其余先收着。有 **置顶** 时，置顶和它下面那一组默认展开。

有会话在等你时，列表顶部会出现 **需要你** 一栏，列出这些会话，点一下直接进去。

卡片大字只放一个身份：有会话名就用会话名；没有的话，若工作区名不是当前目录名，就用工作区名；再否则用终端里像任务的标题（会去掉 `Thinking` / `Waiting for response` 和末尾的 ` - grok`）。都没有时，有 Agent 就写 **claude**，纯终端写 **终端**。下一行永远是坐标，顺序是 **claude · pairfob**（Agent · 目录 · 非默认标签页），不重复大字里已经有的词，也不展示 `main`。不会拿内部 ID 当名称。

- **会话名**：这一块终端画面的名字；改它只影响当前会话
- **标签页名**：装着一个或多个会话的标签页；改它会影响整个标签页的识别
- **工作区名**：最外层项目容器的名字；按工作区分组时就是分组标题

| 状态 | 意思 |
| --- | --- |
| 等你 | agent 在等确认或输入，卡片更醒目 |
| 工作中 | 正在跑 |
| 本轮结束 | 这一轮做完了 |
| 等待输入 | 空着，等你给下一件事 |
| 空闲 | 连着但没在忙 |
| 启动中 | Agent 正在启动 |
| 未知 | 电脑没有报告状态，或暂时确认不了 |

已连接但列表为空时，说明 Herdr 里还没有会话，可以新建一个或在电脑上打开终端。只有页面明确显示 Herdr 没有运行时，才需要打开 Herdr；也可以在电脑上执行 `pairfob doctor` 确认状态。

**新建** 在电脑支持时出现：手机上在右下角，宽屏时在左栏顶部。列表长按或会话 `···` 里的 **新建标签页**，以及会话 `···` 里的 **分屏**，用同一份 Agent 种类列表：可以选一个 Agent，也可以选 **纯终端**。电脑没有列出 Agent 种类时，对话框仍然能开，结果是一个纯终端会话。正在新建的 Worktree 会出现在列表上方，完成前可以取消。

点卡片进去。长按（电脑上右键）可以 **置顶**、在同一工作区再开一页、改名或关闭这份会话。置顶的会话出现在列表最上面的 **置顶** 分组，不再留在原来的工作区或 Agent 组里；再长按 **取消置顶**。标签页已经有可见名字、或正在分屏时，才会出现改标签页名；关整个标签页只在分屏时出现。按工作区时，长按分组标题可以 **在这个工作区新建标签页**、改工作区名，或 **关闭这个工作区**；其他分组方式下，工作区改名和关闭在卡片长按菜单最底下。电脑支持新建标签页时，新建入口才会出现。分屏仍在点进会话后的 `···` 里。

**画板**（卡片长按里的 **看标签页布局** 也能进）打开当前标签页在电脑上的真实分栏。可以捏合或滚轮缩小，一眼看到整个标签页。上面一排是工作区，下面一排是标签页，也可以在这里新建标签页。点一格就打开那个会话。这里切换工作区或标签页不会抢走电脑上的焦点。

手机底部是 **会话** / **画板** / **设置** 三个标签，有会话在等你时 **会话** 上会显示数字。宽屏时这些入口在左栏顶部一排：**新建** / **电脑** / **画板** / **设置**。

## 点进会话

打开会话时默认用 **自动**。这套 Tailscale 直连部署会选择 **控制**；实时会话仍由电脑上的 Herdr 运行。

标题栏：

- 左：返回列表（手机）。有其他会话在等你时，返回键上会显示数量
- 中：Agent 图标、会话名和状态。只是显示，不能点；换会话请回列表，或从左缘右滑
- 右：文件夹 **查看文件与更改**，然后 `···` **会话操作**（怎么看、怎么输入，以及改这一格的名字、关掉这一格）

停止正在工作的 Agent 在输入框右侧的按钮上，见下面的 **控制**。

四个选项在 `···` 最上面的 **模式** 里切换。某个会话里改过，只记住那一个。设置里可以改点开会话时的默认。

| 模式 | 做什么 |
| --- | --- |
| **自动** | 在 Tailscale 直连部署中使用控制；其他模式以可用能力为准 |
| **控制** | 查看终端画面，用系统键盘和按键垫操作这个会话 |
| **终端** | 真终端。vim、全屏 TUI 才需要。手机默认保持 80 列、左右滑动；**适应屏幕** 会把电脑上的终端缩到手机宽度。上下滑仍是远端滚动 |
| **对话** | 和 Agent 发消息。任务从这里发，不在 `···` 菜单。执行过程收成一轮，完成后收起 |

**控制**里：

- 底部输入框用**系统键盘**，听写和自动更正都可用，可以写多行。手机键盘的回车默认换行，写完点 **发送**；想让回车直接发送，在设置里打开 **键盘回车直接发送**。外接键盘上 Enter 发送、Shift+Enter 换行
- 输入框右侧的按钮随情况变化：
  - 有草稿：**发送**，文字进终端并按下 Enter
  - 没有草稿、Agent 正在工作：**停止**。点一下向终端发送 Esc；如果它还在工作，按钮变成 **强制停止**，再点一次才发送 Ctrl+C，而且只发一次。有草稿时长按 **发送** 也能停止
  - 其他时候：**Enter**（↵），向终端发送回车
- **组字 / 实时** 在 `···` → **输入与显示** → **输入** 里切换，只影响这个会话；实时模式下输入框里会标出 **实时**
- 终端里的确认选项保留原样；按提示用按键垫的 ↑/↓ 选择，再按 Enter 确认。需要输入字母或文字时，按终端提示输入
- 点某一行可以 **复制**、**复制路径**、**引用** 到输入框，或 **选择…** 文本
- 上滑或页↑是给当前画面翻页，不是拉取历史
- 字号会记住
- 长行可以自动折行，也可以关掉
- 按键垫第一排是 Esc、方向键和退格。点 `···` 展开后，可以在 **按键** 和 **命令** 之间切换：按键里有 **控制**（Ctrl、Alt、Shift、Cmd、Tab、Shift+Tab、Enter、Ctrl+C 等）和 **选择与编辑** 两页；命令里是 Agent 的斜杠命令（`/clear` 这类会写进终端，Pairfob 不解释）和你自己的常用指令，可以新建、编辑、拖动排序

**对话**模式显示「等你」时，点 **去确认** 会切到 **控制**，查看终端里的确认提示。确认前先读清操作和当前选项；需要时也可以从 `···` → **模式** 切到 **终端**。

电脑和手机操作的是同一个终端中的确认框，一边完成确认后，另一边会看到更新后的状态。如果手机看不到提示，先在电脑上处理，并反馈手机所在模式、Agent / 扩展版本和脱敏录屏。

## 查看文件与更改

会话顶栏的文件夹不是 Worktree 菜单，打开的是这一格的工作区。顶部显示当前分支和领先的提交数：

- **文件** — 目录列表和文本预览
- **更改** — 未提交的 Git 状态，分成 **已暂存的更改** 和 **更改** 两组；点文件看 diff
- diff 页可以在 **已暂存** 和 **工作区** 之间切换，**打开文件** 看全文，底部 **上一个** / **下一个** 逐个翻改动的文件
- 点 diff 的一行写批注，再 **发给 Agent**
- 分支列表只读；切换工作走 Worktree

电脑端 daemon 还不支持时，页面会说明。

## 上传附件

当前直连部署关闭了 P2P。附件选择和上传流程依赖旧传输，因此**这里无法上传文件**。仍可浏览工作区文件和 diff。不要以为选中文件后就会传到电脑。

## 会话操作里可能出现的操作

点会话标题栏右侧 `···`。电脑当时做不到的项不会出现。改标签页名、改工作区名、关闭整个标签页、关闭这个工作区在列表长按菜单里，不在这里。

| 分组 | 可能有 |
| --- | --- |
| 模式 | 自动、控制、终端（vim / TUI）、对话 |
| 快捷格 | 复制屏幕、新标签、分屏、重命名 |
| 输入与显示 | 输入：组字 / 实时（控制）、文字加大 / 减小、长行自动折行（控制）、宽度适应屏幕（终端） |
| 会话 | 布局（拖动分隔线调大小、长按这一格拖到别处交换、铺满）、Worktree（列表、新建、打开）、Agent 信息、关闭会话 |

**对话**把一轮里的思考和工具收成可展开的过程，完成后自动收起。展开可看参数和结果。完成的回答可以 **复制回答**；线程很长时 **加载更早内容**。

网页不会任意执行命令、删 worktree，也不会把电脑窗口抢到前台。

## 设置

手机上点底部的 **设置**；宽屏时在左栏顶部。

- **连接**：显示电脑、这台手机和当前 **Tailscale 直连** 路径，没有 Relay / P2P 网络选择。**添加另一台电脑** 会再建立一条配对；有多台电脑时可 **切换电脑**
- **订阅余量**：这台电脑已登录账号的额度（Codex、Claude Code、GitHub Copilot、Cursor、Grok、Antigravity）。概览是环；**用量详情** 看各窗口。详情页可以 **刷新余量**。没有数据或已过期时不会显示成零
- **语言**：**跟随浏览器**，或固定 **中文** / **English**。只作用于这台设备上的 Pairfob 页面，和文档右上角的语言不是同一项
- **模式**：点开会话时默认用 **自动**，也可以固定为 **控制** / **终端** / **对话**。某个会话里再切换，只记住那一个
- **输入**：新会话默认用组字（写完点发送）还是实时（边打边进终端）。会话里 `···` → **输入与显示** 再切换，只影响那个会话
- **键盘回车直接发送**：默认关，手机键盘回车换行，用发送键发送；打开后回车直接发送。外接键盘始终是 Enter 发送、Shift+Enter 换行
- **通知**：当前 HTTP 直连宿主机不可用，见 [通知](/zh/push)
- **已配对设备**：名称、在线或离线、最近使用、通知。当前设备标成 **这台手机**。其他设备可以点 **解除**；已解除的不再列出
- **导出连接诊断**：连接出问题时导出最近的连接事件，见 [常见问题](/zh/faq)
- **更新电脑端**：直连宿主机可能不提供手机版本查询。发行版可在电脑运行 `pairfob update`，源码构建版需重新构建；见 [命令行](/zh/cli)
- **危险操作**：**解除这台手机的配对**。之后必须重新配对

丢失的手机如果还能打开 Pairfob，也可以从设置里解除其他设备。立刻在电脑上 `pairfob forget` 那台手机，见 [多台设备](/zh/devices)。

## 另一个窗口

同一台已配对设备上，另一个浏览器窗口打开 Pairfob 时，旧窗口可能提示「另一个窗口接管了这台手机」。只用一个打开的页面。

## 加到主屏幕

见[开始使用](/zh/start)。Tailscale IP 上的 HTTP 可能不允许安装 PWA；浏览器页面仍可使用。
