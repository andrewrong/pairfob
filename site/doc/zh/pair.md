# 配对

配对给一台设备的一个浏览器授权。Pairfob 不用账号登录；电脑确认后，浏览器才保存设备凭证。

## 在电脑上

```sh
pairfob pair
```

终端打印二维码和**完整配对链接**。两者都会过期，邀请票据只能用一次。让命令保持运行，等手机到达电脑确认步骤。只使用当前显示的邀请。

## 在手机上

手机先加入同一个 Tailscale 网络。用手机的**系统相机**扫描二维码，就会打开电脑提供的 Pairfob 页面。不能扫码时，在手机上打开电脑的 Tailscale 地址，并把完整链接粘贴到配对表单。

直连页面使用 HTTP，网页内相机可能不可用。仅有 8 位短码不完整；完整链接还包含电脑地址和一次性票据。

票据位于链接的 URL fragment，不随 HTTP 请求发送，但失效前仍应保护整个链接，不要贴到聊天或截图中。

## 在电脑上确认

手机验证配对码后，电脑会请求确认。只有确定是自己的设备时才按 Enter；Ctrl-C 或过期会拒绝。电脑确认之前，配对没有完成。

## 之后使用

在同一个浏览器配置里再次打开电脑的 Tailscale 地址，就会用保存的凭证连接，无需重新扫码。换浏览器配置、清除站点数据或换手机，要重新配对。添加第二台电脑用 **设置 → 添加另一台电脑**；管理设备用 `pairfob list` 和 `pairfob forget N`。

失败后在电脑重新执行 `pairfob pair` 获取新链接；已用过或过期的链接不能重试。见 [排查问题](/zh/troubleshoot)。
